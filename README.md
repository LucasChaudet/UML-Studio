# UML-Studio

Éditeur de diagrammes UML qui fonctionne directement dans le navigateur : un seul fichier, `index.html`, sans installation ni serveur.

## Diagrammes pris en charge
- Classes
- Cas d'utilisation
- Activité (avec couloirs)
- Composants
- Déploiement
- Séquence (lignes de vie, activations, auto-appels, fragments)

La notation suit celle du cours : https://uml.slides.pierre-jehan.com/

## Fonctionnalités
- Enregistrement automatique des projets dans le navigateur, ou dans un dossier de votre choix (Chrome / Edge)
- Export en PDF, PNG, SVG, JSON et `.drawio` (ouvrable dans draw.io)
- Annuler / rétablir, zoom, grille, duplication

## Utilisation
Ouvrir `index.html` dans Chrome ou Edge, ou publier le dépôt avec GitHub Pages.
